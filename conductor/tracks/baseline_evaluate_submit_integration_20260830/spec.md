# Specification: Baseline Evaluation (`evaluate.py`) and Submission (`submit.py`) Integration

## Overview
This track integrates the official KuaiRand-Pure evaluation harness (`src/baseline/evaluate.py`) and submission formatter/validator (`src/baseline/submit.py`) into the MLE-STAR pipeline and task specification. This guarantees that validation metrics generated by candidate models strictly match the competition metric, and that production submissions produced by `FinalArtifactProducer` pass official verification with `submit.py --check`.

## Functional Requirements
1. **Task Specification Alignment (`KuaiRand-Pure.md`):**
   - Explicitly document the validation metric calculation rules from `src/baseline/evaluate.py` (`primary = (GAUC + nDCG@5) / 2.0`).
   - Specify the exact 4-column submission schema (`row_id,user_id,video_id,score`) required by `src/baseline/submit.py`.

2. **Sandbox Environment Plumbing (`SubprocessRunner`):**
   - Inject the workspace root and `src/baseline` into the subprocess `PYTHONPATH` in `SubprocessRunner.run_code`.
   - Allow sandboxed scripts to import `evaluate`, `submit`, or `data` helper modules without `ModuleNotFoundError`.

3. **Production Finalizer Enforcement (`FinalArtifactProducer`):**
   - Update `_FINALIZER_INSTRUCTIONS` and `build_prompt` to mandate generating `./final/submission.csv` with columns `row_id,user_id,video_id,score`.
   - Ensure the script uses the deterministic test order from `submit.py`.

4. **CLI Automated Submission Verification (`cli.py`):**
   - Automatically run submission validation using `submit.py --check` after production artifacts are copied to `./final/`.
   - Report validation success in the summary banner.

## Non-Functional Requirements
- **Coverage:** Maintain >80% test coverage across all modified modules (`sandbox.py`, `finalizer.py`, `cli.py`).
- **Safety:** Prevent sandbox failures and preserve sandboxed subprocess timeouts.
- **Type Safety & Linting:** Pass `mypy src` and `ruff check src` without errors.

## Acceptance Criteria
- [ ] Sandboxed scripts can import `evaluate` and `submit` functions seamlessly.
- [ ] `FinalArtifactProducer` produces a `submission.csv` conforming to the 4-column schema.
- [ ] `submit.py --check` succeeds on the generated submission.
- [ ] All unit and integration tests pass cleanly with `uv run pytest`.
